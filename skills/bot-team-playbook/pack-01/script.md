# Skill Video 02 — bot-team-playbook (OCT blackboard style)

## HOOK
One agent doing everything is a bottleneck with extra steps. Real teams have a manager who never touches the work. Here is the pattern.

## STEP 1 — One bot, one job
One bot, one job. Each profile owns its chat, role, memory, and skills. No universal agents — a bot that does everything does nothing well.

## STEP 2 — Cards go parallel
The orchestrator breaks the big task into cards. Workers pick them up in parallel — one worker per card. Smartest model on top, free models below.

## STEP 3 — Manager never executes
The one line that makes it work: the manager never executes. It hands out, checks every return, allows one focused revision. Workers work, manager manages. One command moves the board.
