# founder-tech-coaching

**Pack:** growth-money

## Use case

'Use when teaching Darren tech to founder-explain level.'

## How to use it

## Procedure

1. Test learner type first with 4 quick questions (build-first action, remember-when, format pick for next concept, 1-line explain with no Googling). Classify from answers (e.g. build-first + diagram-memory + hands-on pick = Builder-Visual) and log it to the governing Multica issue same turn.
2. On any jargon-block signal ('don't understand your language'), restart baby-simple immediately in one everyday analogy (warung/bakso: friend, note, kitchen, cashier). One new term per turn max.
3. Run a 5-minute tiny build: show the map in one line (e.g. Query -> note -> answer), set 3 tiny docs, do one live run, then a break-it A/B test. End every turn with one tappable A/B, never a lecture.
4. Demand teach-back (Feynman): ask for a 1-line messy explanation in Darren's own words, then polish it into one reusable founder line and hand it back.
5. For 100% + spot-the-gap, drill failure-first in this order: wrong note, old/stale note, date-check before cooking, loop-stuck/stop-rule, cost blow, wrong-tool routing, missing memory. One drill per turn.
6. Keep math-lite always: words get addresses, close addresses = similar meaning, training = turning knobs until guesses hurt less. Counts and pictures only, no equations first.
7. On 'fully map me / no exposure' requests, deliver the 6-zone shield (LLM, RAG notes, Agent warung, freshness+eval, cost+safety, shipping) plus tough-question answers, as airy chat summary plus a `Founder_AI_Shield.txt`-style file sent via MEDIA: absolute path.
8. Live-sync Multica every turn: `multica issue comment add <uuid> --content "..."` on the governing issue before replying; never local-only memory.

## Pitfalls

- On jargon-block signals restart plain immediately instead of re-explaining with harder words — stacking terms on confusion causes quit.
- Introduce one term per turn max — Builder-Visual locks by touching then naming, and stacked terms blur the map.
- Keep each drill to a single failure mode per turn — combined modes hide which intuition just clicked.
- File plus chat for shields: chat summary alone gets lost, file alone never gets read — send both, chat first then MEDIA: path.
