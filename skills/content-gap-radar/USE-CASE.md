# content-gap-radar

**Pack:** content-fleet

## Use case

Use when deciding what content to make next.

## How to use it

## Procedure

1. **Inventory** (read-only first): local repo builds (`fleet-school-repo/`),
   published pages, vault Fleet-Memory, Discord posts, YouTube catalog via
   available read tools.
2. **Score** each item: shipped vs WIP, has video vs text-only, linked in
   funnel vs orphaned.
3. **Report gaps** ranked by effort-to-value: orphans to wire in, WIPs to
   finish, winners to sequel. Each gap = one tappable next step.
4. **Never invent metrics** — view counts and ranks come from tool output or
   are labeled unknown.

## Pitfalls

- Portfolio rule: only finished shipped work counts as coverage; WIPs are
  gaps, not assets.
- One radar run answers 'what next' for a week — rerun, don't re-derive.

## Install

Copy `SKILL.md` into your agent's skills directory (Hermes: `~/.hermes/skills/content-gap-radar/`). Video walkthrough ships with the pack.
